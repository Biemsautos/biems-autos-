BIEMS AUTOS — INSTALLABLE CAR SALES DASHBOARD

Included:
- index.html: app
- manifest.json: install/home-screen configuration
- sw.js: offline app shell
- icon.svg: temporary BA icon, replace when company logo is supplied

How to publish/install:
1. Upload all files to any HTTPS web hosting.
2. Open the HTTPS address on Android.
3. Tap Install App when offered, or browser menu > Add to Home screen.
4. The installed app runs in standalone mode without the browser address bar.

Important:
- Vehicle photos/videos and listings are stored in the device browser/app storage. This is a local first version; it does not synchronize across phones.
- WhatsApp quotation opens the official WhatsApp web/app URL with a prefilled quotation. The client must still press Send in WhatsApp.
- For larger videos or multi-device staff access, a cloud database/storage backend should be added in the next version.
